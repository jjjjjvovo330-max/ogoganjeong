오고간정 개인정보처리방침

시행일: 2026년 11월 18일

요약: 오고간정은 회원가입, 로그인, 서버, 광고, 분석 도구가 없습니다. 사용자가 입력한 경조사 기록은 사용자의 휴대폰 안에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

1. 처리하는 정보

오고간정(이하 “앱”)은 개인정보를 수집하지 않습니다. 사용자가 앱을 쓰면서 직접 입력한 아래 정보는 앱이 동작하기 위해 사용자의 기기 안에만 저장됩니다.

정보저장 위치개발자 전송
경조사 기록(이름, 별칭, 관계, 행사, 금액, 날짜, 메모)기기 안 앱 저장소없음
경조사 일정(행사 이름, 날짜, 시간, 장소, 메모)기기 안 앱 저장소없음

2. 문자(SMS) 내용

‘문자에서 금액 가져오기’는 사용자가 직접 복사해 붙여 넣은 글에서 금액 후보만 찾아 보여 줍니다. 앱은 문자 읽기 권한을 요청하지 않으며, 붙여 넣은 문자 내용은 저장하거나 전송하지 않습니다.

3. 제3자 제공과 처리 위탁

앱은 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다. 광고 SDK, 분석 도구, 외부 서버를 사용하지 않습니다.

4. 사용자가 직접 내보내는 파일

사용자가 ‘백업 파일 만들기’, ‘백업 파일 공유하기’, ‘CSV 내보내기’를 누르면 장부 내용이 담긴 파일이 만들어집니다. 이 파일을 어디에 저장하거나 누구에게 보낼지는 사용자가 직접 고르며, 앱이나 개발자는 그 파일에 접근하지 않습니다. 파일에는 이름과 금액 등 개인정보가 들어 있으니 안전한 곳에 보관해 주세요.

5. 의견 보내기

‘의견 보내기’를 누르면 사용자의 메일 앱이 열립니다. 사용자가 직접 메일을 보낸 경우에만 개발자가 그 메일(보낸 사람 주소와 내용)을 받으며, 답변과 앱 개선에만 사용하고 답변이 끝나면 지체 없이 삭제합니다. 메일에는 앱 버전만 자동으로 들어가고 장부 내용은 들어가지 않습니다.

6. 보관 기간과 삭제

  • 기록은 사용자가 지울 때까지 기기 안에 남습니다. 지운 기록은 휴지통에 30일 동안 보관된 뒤 자동으로 삭제됩니다.
  • 앱을 삭제하거나 휴대폰 설정에서 앱 데이터를 삭제하면 모든 기록이 지워집니다.
  • 개발자는 사용자의 기록을 보관하지 않으므로 대신 복구해 드릴 수 없습니다. 백업 파일을 만들어 두세요.

7. 접근 권한

앱은 연락처, 문자, 위치, 카메라, 저장공간 권한을 요청하지 않습니다. 백업 복원과 CSV 가져오기는 Android 기본 파일 선택 화면에서 사용자가 고른 파일만 읽습니다.

8. 아동의 개인정보

앱은 만 18세 이상 성인을 대상으로 하며, 아동의 개인정보를 수집하지 않습니다.

9. 이용자의 권리

모든 정보가 사용자의 기기에만 있으므로 사용자는 앱 안에서 언제든지 기록을 열람, 수정, 삭제할 수 있습니다. 궁금한 점은 아래 연락처로 문의해 주세요.
